# GFriend Sample Scripts
Here is sample GFriend test scripts for various kinds of situation. Hope that they will help you to understand GFriend deeply.

## Samples

[Variables](Variables/README.md) : Basic usage of variable.

[Flow Control and Operator](FlowControl/README.md) : Basic flow control with Repeat, For, While and If statements, usage of operators

[Data Driven Test](DataDrivenTest/README.md) : Data driven test sample with Excel raw data.

[Json Library](JsonLibrary/README.md) : Json library examples.

[Info](Info/README.md) : Performance measure examples.

[LogInfo](LogInfo/README.md) : LogInfo captures the start , end time and elapsed time of each loop iteration, along with chart representation .

[Memory Collectors](MemoryCollectors/README.md) : Memory collector Sample scripts.

[Return Statements](ReturnStatements/README.md) : Basic usage of Return With Pass/Fail/Error

[Vision](Vision/README.md) : Basic usage of Vision with both Tesseract and Azure Vision.

[SpreadSheet](SpreadSheet/README.md) : Basic usage of SpreadSheet library.
