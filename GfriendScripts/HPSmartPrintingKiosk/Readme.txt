Steps to follow before running the script 
------------------------------------------
1. Device time should be same as your time zone.
2. Place text document in this path C:\Users\rdladmin\ and name the document as Document_To_print
3. Select authentication type by changing as Y or N accordingly in variable file for ${PIN_AUTH)) variable


note:
//For PIN Authentication, provide the variable (${PIN_AUTH) value as Y
//For Username and password Authentication, provide the variable (${PIN_AUTH)) value as N
