Prerequisities:
---------------
1.User must have valid user account created in ePRINTit webportal.
2.User need to provide the ${Username} and ${Password} values in the ePRINTit.gfvar file.
3.Create a sample text file or document in the local system which will be used for uploading to ePRINTit webportal for printing.
4.${Documentpath} in ePRINTit.gfvar file should be provided i.e., the above local file path.
5.Provide ${txtname} value as the name of document created in local system.
