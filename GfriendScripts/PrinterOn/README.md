Prerequisities
1.Printer should the added in the PrinterOn Server by the user.
2.Added Printer must be specified in the gfvar file.
3.User should add the 'Open Print Page' URL in the gfvar file and the change the URL to the specified PrinterOn Server.
  Example:- "https://127.0.0.1/cps" to "https://PrinterOn Server IP/cps" (https://146.205.2.149/cps)	
4.Filepath and Filename should be specified in the gfvar file.
