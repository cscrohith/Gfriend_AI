Prerequisites
1.Device must be enabled with HP Workpath Debug Bridge.
2.HP Workpath platform must be enabled in the EWS Page.
3.Deice must have RAM greater than 3GB.
4.Printix Go Workapath app should be installed on the device from HPK Tool.
5.gfvar file must be edit in order to make application work on required user configuration.	

Note
Due to UI restrictions, there are some hard coded values that user has to take care before running this Scripts.
User can go through the Printix.gfvar file for more details explanation on how to change this hard coded values according to user requirement.
