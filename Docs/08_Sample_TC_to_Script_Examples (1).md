# Sample TC to Script Examples

## Purpose

This document provides real worked examples — manual test case input → expected GFriend automation script output. These examples serve as:

1. **Ground truth** for validating the AI agent's output quality
2. **Training data** for the knowledge base (add to `knowledge_base/scripts/`)
3. **Developer reference** for understanding what correct output looks like

---

## Example 1 — Web Login Test

### Input (Custom Template)

| Field | Value |
|-------|-------|
| TC_ID | TC-001 |
| TC_Title | Verify user can login to web portal with valid credentials |
| Domain | Web |
| DUT_Type | - |
| DUT_Address | - |
| TC_Type | Functional |
| Priority | High |
| Preconditions | Web portal is accessible at http://portal.example.com. Valid test user account exists (admin / Admin@123). Chrome browser installed. |

| Step # | Step Action | Expected Result |
|--------|------------|----------------|
| 1 | Open Chrome browser and navigate to http://portal.example.com | Login page is displayed with username and password fields |
| 2 | Enter "admin" in the Username field | Username field shows "admin" |
| 3 | Enter "Admin@123" in the Password field | Password field is populated (masked) |
| 4 | Click the Login button | User is redirected to the Dashboard page |
| 5 | Verify the Dashboard page is displayed | Dashboard title or heading is visible |
| 6 | Take a screenshot for evidence | Screenshot captured |
| 7 | Click Logout | User is redirected back to Login page |
| 8 | Verify Login page is displayed | Login page is shown |

### Expected Output Script (`TC-001_Web_Login_Test.txt`)

```javascript
// Generated by GFriend AI Agent
// TC ID: TC-001
// TC Title: Verify user can login to web portal with valid credentials
// Generated: 2026-06-15T10:00:00
// Status: DRAFT - REQUIRES DEVELOPER REVIEW
// Validation: PASSED

${Username}=admin
${Password}=Admin@123
${PortalUrl}=http://portal.example.com

using Web

Verify user can login to web portal with valid credentials
{
    Web.Open With Chrome(${PortalUrl})
    Web.Wait For Text(Username, 10)

    Web.Set Text(#username, ${Username})
    Web.Set Text(#password, ${Password})
    Web.Click(#login-button)

    Web.Wait For Text(Dashboard, 10)
    Web.Check Text Exists(Dashboard)
    Web.Capture Screen Shot(Dashboard_Verified)

    Web.Click(#logout-link)
    Web.Wait For Text(Login, 10)
    Web.Check Text Exists(Login)
}
```

### Expected Output Script (`TC-002_Mobile_Print.txt`)

```javascript
// Generated by GFriend AI Agent
// TC ID: TC-002
// TC Title: Verify user can print a document from Android phone to HP printer
// Generated: 2026-06-15T10:00:00
// Status: DRAFT - REQUIRES DEVELOPER REVIEW

using Android As MobileDevice

    MobileDevice.Wait For Text(Sent, 15)
```

| Section | REST API Tests |
| Type | Functional |
| Priority | Critical |

| Expected Result | 1. Header set\n2. Request sent\n3. Status 200 received\n4. Token field present in JSON\n5. Token captured |

```javascript
// Generated by GFriend AI Agent

${ApiUser}=testuser
${ApiPassword}=Test@123

using REST

Verify REST API returns 200 for valid login
```

## Example 5 — SSH Server Validation Test

### Input (Custom Template)

| Field | Value |
|-------|-------|
| TC_ID | TC-005 |
| TC_Title | Verify SSH connectivity and log file exists on server |
| Domain | SSH |
| DUT_Type | Server |
| DUT_Address | 192.168.1.100 |
| TC_Type | Functional |
| Priority | Medium |
| Preconditions | Server at 192.168.1.100 is running Linux. SSH credentials: user=testadmin, password=Admin@123. Log file expected at /var/log/app/app.log. |

| Step # | Step Action | Expected Result |
|--------|------------|----------------|
| 1 | Connect to server via SSH | SSH connection established |
| 2 | Execute command: ls /var/log/app/ | Command output shows directory listing |
| 3 | Verify app.log file is present in the output | "app.log" visible in output |
| 4 | Execute command: tail -n 5 /var/log/app/app.log | Last 5 lines of log shown |
| 5 | Disconnect SSH session | Session closed |

### Expected Output Script (`TC-005_SSH_Server_Validation.txt`)

```javascript
// Generated by GFriend AI Agent
// TC ID: TC-005
// TC Title: Verify SSH connectivity and log file exists on server
// Generated: 2026-06-15T10:00:00
// Status: DRAFT - REQUIRES DEVELOPER REVIEW
// Validation: PASSED

${ServerIP}=192.168.1.100
${SSHUser}=testadmin
${SSHPassword}=Admin@123
${LogPath}=/var/log/app/app.log

using SSH

Verify SSH connectivity and log file exists on server
{
    SSH.Connect(${ServerIP}, ${SSHUser}, ${SSHPassword})

    SSH.Execute(ls /var/log/app/, ${Buffer})
    SSH.Check Output Contains(app.log)

    SSH.Execute(tail -n 5 ${LogPath}, ${Buffer})

    SSH.Disconnect()
}
```

## Quality Comparison — Before and After AI Agent

| Metric | Manual Script Writing | With AI Agent |
|--------|----------------------|--------------|
| Time to first draft | 20–45 min per TC | 3–10 seconds per TC |
| Requires GFriend expertise | Yes — know all keyword names | No — agent retrieves keywords |
| New joiner capable | After 2–3 weeks training | Day 1 (with review) |
| Consistency of variable naming | Variable | Consistent (follows patterns) |
| Missing `using` statements | Common mistake | Caught by validator |
| AlwaysPass accidentally set | Possible | Blocked by validator |
